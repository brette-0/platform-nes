Demo Overview
=============

This document will discuss how the demo uses ``platform-nes`` lib features to
platform agnostically create the 'Super Mary Sisters' platforming adventure game.

This resource should be used to help understand how to use the library, and may also
be used for general (or games) programming ideas.
